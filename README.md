To-Do Task Manager Web App

Project Overview

The To-Do Task Manager is a browser-based productivity application built
using HTML, CSS, and JavaScript. It allows users to manage daily tasks
efficiently with real-time progress tracking and local storage
persistence.

Features

-   Add new tasks
-   Edit existing tasks
-   Delete tasks
-   Mark tasks as completed
-   Progress tracking bar
-   LocalStorage data persistence
-   Confetti animation on full completion
-   Empty-state illustration when no tasks exist
-   Responsive user interface

Technologies Used

-   HTML5 – Structure and layout
-   CSS3 – Styling and responsive design
-   JavaScript (Vanilla JS) – Application logic
-   Font Awesome – Icons
-   LocalStorage API – Data persistence
-   tsParticles Confetti – Completion animation

Installation and Setup

1.  Clone the repository: git clone
    https://github.com/your-username/todo-task-app.git

2.  Navigate to the project folder: cd todo-task-app

3.  Open the application: Open index.html directly in your browser OR
    use VS Code Live Server.

How It Works

-   Tasks are dynamically created using JavaScript DOM manipulation.
-   Each task includes a checkbox, edit button, and delete button.
-   Task data is stored using LocalStorage to persist after page
    refresh.
-   The progress bar updates automatically based on completed tasks.
-   Confetti animation triggers when all tasks are completed.
